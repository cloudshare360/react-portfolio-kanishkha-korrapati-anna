# Kanishkha Korrapati Anna — Portfolio

Recruiter-focused finance and analytics portfolio built with React 18 and Create React App, based on the deployment model of the Tanmayi reference repository.

## Run locally

```bash
npm install
npm start
```

## Verify and deploy

```bash
npm run build
npm run deploy
```

Read `docs/CONTENT_SOURCE_OF_TRUTH.md` before changing claims and `docs/PROJECT_PLAN.md` for release status. Deployment is configured for `https://cloudshare360.github.io/react-portfolio-kanishkha-korrapati-anna`.
